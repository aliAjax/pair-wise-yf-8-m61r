# 胶片分镜条·多卷放映包核对台

纯前端本地应用（无后端，数据写浏览器 `localStorage`，刷新保留），用于整理纸质放映胶片：
多放映包、多片卷、片段录入、拖拽排序、拆卷/合卷、试映前破损与颜色偏移提醒、筛选与导出。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 功能

- **多放映包**：新建 / 改名 / 删除放映包，切换后统计、颜色与破损筛选、提醒、导出全部按当前包同步。
- **旧数据自动迁移**：旧版单卷数据（`{reelTitle, segments}`）首次打开自动迁移为只含一卷的放映包，卷号取旧胶片卷标题。
- **拆卷**：只在同一卷相邻片段之间的接缝处拆；左卷守住原编号，右卷领取新卷号。
- **合并**：仅相邻两卷可合并，合并后保留左卷编号，卷序与片段顺序不变。
- **整次拒绝**：编号重复、片段时长为零、标记"需跳过"但缺少备注，或新卷号重号时，拆/并整次拒绝，卷序和清单不变。
- **撤销**：每次成功的拆卷/合并都会生成一个可撤销版本（按放映包独立、最多 20 步），撤销恢复片段、卷号与顺序；被拒绝的操作不产生版本。
- **筛选**：颜色偏移 + 破损情况 + 关键词；筛选生效时隐藏拆卷/合并入口，避免跨筛选误操作。
- **导出**：按卷分组导出当前放映包的纯文本清单。

## 测试

- 核心规则（迁移、校验、拆/并、撤销）：`node --test`
- 浏览器端冒烟（迁移渲染、拆并撤销、切包同步、导出、刷新保留）：`node smoke.test.js`
  （冒烟脚本依赖 `jsdom`，不随运行时安装）
