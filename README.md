# 胶片分镜条核对台 · 多卷放映包

一个纯前端本地应用（不接后端），用来把纸质放映胶片整理成「放映包 → 胶片卷 → 片段」，支持拆卷、合卷、拖拽排序、时长/破损统计、颜色与破损筛选、试映前提醒和清单导出。数据写浏览器 localStorage，刷新后保留。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 数据层级

- **放映包**：一次放映的完整集合，可建多个，通过顶部下拉切换；可重命名、删除（至少保留一个）。
- **胶片卷**：每个放映包含若干卷，用 A、B、C… 编号；卷按顺序排列。
- **片段**：录入选定卷，含编号、时长、颜色偏移、破损情况、缩略图与备注；只可在同一卷内拖拽或用 ↑↓ 排序。

## 旧版单卷数据迁移

沿用原 localStorage 键。首次用新版打开旧数据（结构为 `{reelTitle, segments}`）时会自动迁移为「单卷放映包」：

- 放映包名取旧卷名（无旧名则用“旧版迁移放映包”）；
- 原片段整体放入 A 卷，编号、时长、备注与顺序全部保留；
- 迁移只执行一次，已是多卷结构的数据不会被重复迁移。

## 拆卷与合卷

- **拆卷**：只在同一卷两个相邻片段之间进行（卡片之间的「✂ 在此相邻片段之间拆卷」）。左侧卷守住原编号，右侧卷领取当前最小可用的新编号（如 A、B 已占用则领 C）。
- **合卷**：仅相邻卷可合并（卷头「合并到下一卷 →」）。合并后片段顺序为左卷后接右卷，并沿用左侧卷编号。

### 整次拒绝

拆/并会先在“操作之后”的卷上整体校验，任一不通过则整次拒绝、卷序与清单完全不变，并提示原因：

1. 卷内出现**重复片段编号**（或编号为空）；
2. 片段**时长为零或无效**（≤ 0）；
3. 破损为**需跳过**的片段**没有备注**。

被拒绝的操作不会产生撤销记录。

### 撤销

每次成功的拆/并都会生成一个可撤销版本（按放映包各自保存）。点击顶部「↶ 撤销拆/并」可逐步回退，恢复当时的片段、卷号和卷顺序。撤销栈保存在内存中（最多 100 步），刷新页面后清空；业务数据本身始终持久化在本地。

## 切换放映包后的联动

切换放映包后，以下内容立即按新包重新计算：总时长/卷数/破损数/片段数统计、颜色筛选、破损筛选、搜索、试映前提醒（标注所属卷）以及导出清单。筛选器本身的选择在切换后保持，会直接应用到新包上。

## 导出

导出当前放映包的纯文本清单：按卷分组，列出每段编号、时长、颜色、破损与备注，文件名取放映包名称。
